# E-Commerce Sales Analysis Dashboard

## 📊 Project Overview

This Power BI dashboard provides a comprehensive analysis of e-commerce sales performance across different states, product categories, customers, and payment methods. The dashboard enables businesses to monitor key performance indicators (KPIs), identify sales trends, and gain actionable insights for data-driven decision-making.

## 🎯 Objectives

* Analyze overall sales and profit performance.
* Identify top-performing product categories.
* Track sales distribution across states and cities.
* Understand customer purchasing behavior.
* Evaluate the effectiveness of different payment methods.
* Support strategic business decisions through interactive visualizations.

## 📂 Dataset Information

The project uses two datasets:

### Orders Dataset

Contains customer and order-related information:

* Order ID
* Order Date
* Customer Name
* State
* City

### Details Dataset

Contains transaction-level details:

* Order ID
* Amount
* Profit
* Quantity
* Category
* Sub-Category
* Payment Mode

## 🔍 Key Insights

* Electronics generated the highest revenue among all categories.
* Maharashtra recorded the highest sales contribution.
* Cash on Delivery (COD) was the most preferred payment method.
* Clothing category accounted for the largest number of orders.
* Significant opportunities exist to improve profitability across certain product segments.
